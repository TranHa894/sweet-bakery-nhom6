# Giao diện đã tích hợp
Đọc README.md ở thư mục ngoài cùng để chạy toàn hệ thống.
Không dùng Live Server hoặc mở HTML trực tiếp. Chạy CHAY-WEBSITE.bat, mở http://127.0.0.1:8000.
Danh mục và đặt hàng gọi API cùng origin. Dữ liệu products.json chỉ seed lần đầu; products.js giữ làm tham khảo cũ, không còn được HTML nạp.
